# Ethernet

## ¿Qué es?

Una familia de estándares para conectar equipos en una red local, normalmente
mediante cables y switches. Su referencia principal es IEEE 802.3.

## ¿Cómo funciona y para qué sirve?

Transporta **tramas** con direcciones MAC de origen y destino. Los switches
aprenden qué dispositivos están conectados a sus puertos y reenvían las tramas.
Se utiliza en oficinas, centros de datos y conexiones de servidores.

## Ideas clave

- Una MAC identifica una interfaz en el enlace; una IP permite direccionamiento entre redes.
- Ethernet transporta paquetes IP, pero no reemplaza IP, TCP ni HTTP.
- El enlace cableado no cifra por sí solo los datos de una aplicación.

**Referencia:** [IEEE 802.3](https://www.ieee802.org/3/).
