# Origen de las prácticas

## ¿Qué es este índice?

Relaciona los temas educativos con los manuales analizados. No reproduce sus
datos internos, URLs privadas, responsables ni credenciales. Los archivos de
origen siguen en la carpeta de manuales que proporcionaste; no se copian aquí.

## General

Fuente: BUENAS PRACTICAS - COMPLETO.docx. Incluye nombrado Python y Java,
configuración, arquitectura Angular, rendimiento Python, pruebas de contratos,
resiliencia, patrones, MCP, skills y procesos de programación.

## Angular

Fuentes: Manual_Nombrado_Angular.pdf y la sección de arquitectura Angular del
documento general. No se incluyen ejemplos de React porque el frontend de este
ejercicio es Angular. Su guía se revisó, pero no se traslada su Atomic Design como
una obligación a Angular.

## Spring

Fuentes: Manual_Pruebas_Spring_Boot.pdf y las secciones Java del documento general.
Manual_Pruebas_Unitarias_NET.pdf aporta ideas compartidas de pruebas, como AAA y
aislamiento; sus herramientas no se presentan como herramientas de Java o Python.

## Database

Fuentes: Manual_Estandares_Bases_Datos.pdf y Manual_Nombrado_Objetos_BDD.pdf.
Los ejemplos están adaptados a PostgreSQL y evitan sintaxis exclusiva de SQL Server.

## Git-flow

Fuentes: Revision Pares/Manual_Git_Flow_Despliegues.pdf y el flujo PR del documento
general. Los aprobadores de producción requieren aclaración antes de automatizar
una política.

## Peer-review

Fuentes: Revision Pares/Manual_Revision_Cruzada_Cambios_Normales.pdf y STD_GEN_001
del documento general. Se conserva la distinción entre revisión y evidencia.

## Ai

Fuente: Manual_Usuario_Area_IA.pdf. Aporta reutilización, responsabilidad,
trazabilidad y gobierno según autonomía y reversibilidad. MCP y skills se
describen en el documento general.
