# Arquitectura y responsabilidades

## ¿Qué es?

Cómo separar el negocio, las herramientas y la entrada HTTP en Python y Spring Boot.

## Cómo estudiar este bloque

Cada subtema tiene una definición en español y ejemplos apropiados para la
tecnología indicada. Lee primero qué problema resuelve y después compara los
archivos de la carpeta. Los procesos de entrega e IA se muestran como casos de
análisis, no como scripts que ejecutan cambios reales.

| Orden | Tema | Tecnología |
|---|---|---|
| 01 | [Separación de responsabilidades](01_separation_of_responsibilities/definition.md) | Python; el mismo criterio se aplica a controladores y servicios de Spring Boot |
| 02 | [Inyección de dependencias](02_dependency_injection/definition.md) | Python; Spring Boot realiza la composición mediante beans e inyección por constructor |
| 03 | [Puertos y adaptadores](03_ports_and_adapters/definition.md) | Python |
| 04 | [Aplicación Flask por responsabilidades](04_flask_application_structure/definition.md) | Python y Flask |
| 05 | [Aplicación Spring Boot por responsabilidades](05_spring_boot_structure/definition.md) | Spring Boot 3.5.16 y Java 21 |
