# Manejo de errores

## ¿Qué es?

Cómo comunicar fallos sin ocultarlos ni perder su causa.

## Cómo estudiar este bloque

Cada subtema tiene una definición en español y ejemplos apropiados para la
tecnología indicada. Lee primero qué problema resuelve y después compara los
archivos de la carpeta. Los procesos de entrega e IA se muestran como casos de
análisis, no como scripts que ejecutan cambios reales.
