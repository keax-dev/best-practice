# Condiciones y comparaciones

## ¿Qué es?

Es escribir condiciones que distingan lo que realmente quieres comprobar: ausencia, colección vacía o un tipo de dato.

## ¿Cómo funciona y para qué sirve?

Usa is None para ausencia y evalúa directamente una lista para saber si tiene elementos. Para cantidades enteras, recuerda que bool también pertenece a int en Python.

## Qué muestra el ejemplo

before.py acepta True. after.py lo rechaza y diferencia una lista ausente de una lista vacía.

Tecnología: **Python**.

## Cómo revisarlo o ejecutarlo

Desde la raíz del repositorio:

```powershell
.\.venv\Scripts\python.exe -B .\BP\01_python_standards\04_conditions_and_comparisons\before.py
.\.venv\Scripts\python.exe -B .\BP\01_python_standards\04_conditions_and_comparisons\after.py
```

## Qué pide la organización

La guía interna pide aplicar esta práctica según el tipo de componente. Los valores del ejemplo son didácticos y no representan parámetros productivos aprobados.

## Límites y aclaraciones

El ejemplo aísla una práctica. No representa una aplicación completa ni todas sus validaciones.
