# Construcción de cadenas

## ¿Qué es?

Es preparar texto de forma legible, usando f-strings para valores y join para reunir una colección de textos.

## ¿Cómo funciona y para qué sirve?

join expresa la unión de varios elementos y f-strings muestran dónde se insertan los valores. Mantén un estilo de comillas consistente.

## Qué muestra el ejemplo

Las dos versiones imprimen Products: Coffee, Tea.

Tecnología: **Python**.

## Cómo revisarlo o ejecutarlo

Desde la raíz del repositorio:

```powershell
.\.venv\Scripts\python.exe -B .\BP\01_python_standards\03_strings\before.py
.\.venv\Scripts\python.exe -B .\BP\01_python_standards\03_strings\after.py
```

## Qué pide la organización

La guía interna pide aplicar esta práctica según el tipo de componente. Los valores del ejemplo son didácticos y no representan parámetros productivos aprobados.

## Límites y aclaraciones

No se prohíbe toda suma de cadenas: unir dos literales puede ser sencillo. join aporta claridad al trabajar con colecciones.
